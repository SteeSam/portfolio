Steven is a recent Computer Engineering and Information Technology graduate from the United African University of Tanzania (UAUT), based in Dar es Salaam. His work centers on a simple observation: many operational problems facing fast-growing East African cities — uncollected waste, paper-based records, unclear market navigation — don't need expensive new hardware. They need better software, built around how people actually work.

That thinking shaped his capstone project, Safisha, a map-based waste collection system for Kigamboni Municipality that replaces physical IoT sensors with a "human-as-a-sensor" model.

Alongside engineering, Steven has worked as a UI/UX designer through an internship at SQRock, designing flows and design systems for a consumer mobile app and an enterprise dashboard.

// case-study — featured

Safisha

Sole developer — capstone project, supervised by Mr. Florian Rwegoshora, UAUT

Problem. Kigamboni Municipality's waste collection ran on fixed schedules with no visibility into actual accumulation — leading to overflow and no way to verify contractor work.

Solution. A "human-as-a-sensor" platform: citizens report waste via geotagged photos, an admin dashboard dispatches collectors on a live map, and a proof-of-work check blocks task closure unless the collector is within 50 meters of the site.

  • Citizen app (Flutter): one-tap geotagged photo reporting with live status tracking
  • Admin dashboard (React + Leaflet + OpenStreetMap): real-time GIS map, dispatch controls
  • Collector app (Flutter): distance-sorted queue, navigation, mandatory proof-of-work photo
  • 50m Haversine geofence lock — mathematically blocks fraudulent task closure
  • Supabase / PostgreSQL backend in 3NF with Row-Level Security and real-time sync
Flutter / DartReactLeafletSupabasePostgreSQL
▶ Live demo walkthrough — citizen report → admin dispatch → collector geofence lock

Full prototype built across all four subsystems and field-piloted in Kigamboni Municipality; the functional test suite (GPS capture, real-time sync, dispatch routing, geofence lock/unlock) passed end to end. Offline sync was identified as the top priority for future work.
